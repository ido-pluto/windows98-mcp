WIN98CTL - RELEASE DOWNLOAD
===========================

This is the Windows 98 guest component for windows98-mcp.

1. Extract this folder and edit WIN98CTL.INI. Set host to the host-only adapter
   address visible from Windows 98 and set port to the host listener port.
2. Copy the complete folder to Windows 98.
3. Run RUNTEST.BAT, then WIN98CTL.EXE.
4. On the host, start the Windows admin app or run npx windows98-mcp.
5. Run INSTALL.BAT only after the host smoke test passes.

The Windows 98 guest always connects outbound to the host. It retries every
two seconds. Protocol v2 has no secrets, authentication, or encryption; use it
only on an isolated VM network.
